  override included adjacent pool bytes. The production contract now preserves
  actual 72-byte patches and applies their fields to generated cores.
- `galaxy-allocator-validation-initial.json`: 41 differences from omitting the
  stellar initializer's 0x2ca00 allocation extent. Source-derived allocation
  accounting corrected them; the initial receipt remains.
- `companion-conditional-check-attempt-1.json` and `-attempt-2.json`: original
  conditional comparison, including the corrected light-year constant and
  historical spectral-table initialization differences.
- `companion-fresh-native-adapter-failure.json` and the first fresh-check attempt:
  instrumentation failures/corrections retained before the successful oracle run.
- `companion-standalone-neighbor-check.json`: 32 historical neighbor records in
  18 cases differ only in spectral flag bytes 64/65; those old receipts omitted
  spectral initialization. This is separate from the fresh acceptance.
- `companion-e2e-check-v1.json`: all 24 raw companion padding observations, with
  offsets and both full records. The native leaves those bytes unwritten.
- `benchmark-bulk/BENCHMARK.json`: initial per-address dispatch caused redundant
  boxel generation and reached 1,280 records/s with 16 workers. Bounded grouping
  raised the same workload to 2,847 records/s; both receipts are retained.
- The initial integration stopped on a missing provider interface before making
  a comparison. The scheduler now uses recovered override membership, exact
  influence arguments, and the verified +0x90 metallicity provider. The initial
  validator also rejected relative paths before comparison; path handling was
  corrected. Neither aborted run produced an acceptance claim.
